¿Cómo funciona?

La bolsa incorpora un sensor de luz en su interior. Cada vez que se abre para sacar la botella, entra luz y el sistema reinicia el temporizador.

Componentes del sistema

Componente Función
Sensor de luz (LDR) Detecta la apertura de la bolsa
LilyPad ATmega328 Controla la lógica del sistema
LED / Vibrador Avisa al usuario de forma discreta

Lógica del recordatorio

Si la bolsa no se abre durante un periodo prolongado, el sistema activa una señal suave. Al volver a abrirla, el aviso se desactiva automáticamente.
